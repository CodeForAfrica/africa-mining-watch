Areas measured on ESRI:102022 (Africa Albers Equal Area Conic), verified against
geodesic areas to within 0.000%.

**A note on "area".** The boundary file mixes administrative levels: ADM2 for eight
countries and ADM3 for six. What that unit is called locally therefore varies —
districts in Ghana and Liberia, territories in DR Congo, chiefdoms in Sierra Leone,
local government areas in Nigeria, sub-prefectures in Guinea and Côte d'Ivoire,
communes in Cameroon and the Central African Republic, prefectures in Togo,
departments in Gabon. This document and the map therefore use the neutral
"administrative area", and every row carries a `shapeType` of `ADM2` or `ADM3` so
the level is never ambiguous.

## Method

1. Each dissolved polygon is one detection. The two surveys share no geometry, so
   they simply add.
2. Every footprint is **clipped against every area it intersects**, and only
   the clipped hectares are credited to that area. This matters: 1,182
   footprints straddle an internal boundary and one spans 15 areas, so
   assigning whole footprints by centroid would have misplaced large areas.
3. `detections` counts footprints *touching* an area — a straddling footprint
   is counted in each area it reaches. `sites_hosted` in the CSV counts only
   footprints whose interior point falls in the area, and that column does sum
   to 12,874.
4. 12,828 footprints fall inside an area outright; 46 sit in gaps left by
   boundary simplification and were snapped to the nearest area (none further
   than 4.1 km). 26 produce no usable intersection and fall back to that snapped
   area. Nothing is discarded.

## Caveats — read before publishing any of these figures

- **No protected-areas layer was supplied.** The boundary file is geoBoundaries
  ADM2/ADM3 — ordinary administrative units. Nothing in the three files
  identifies a national park, forest reserve or Ramsar site, so "protected areas
  touched" and "most impacted protected area" cannot be answered from this data
  alone. `protected_areas.py` answers both as soon as a WDPA extract is unpacked
  under `wdpa/` — see that folder's README for the download steps, and
  the "Protected areas" section below for what the pipeline does and does not
  count.
- **One footprint holds a fifth of the mined area.** The largest dissolved polygon
  is 176,992 ha — 20.4% of everything detected — sprawling 74 × 128 km across 15
  administrative areas of the Ghanaian gold belt. The dissolve fused hundreds of neighbouring
  sites into one feature, so it counts as a single detection. Site counts are
  therefore conservative wherever mining is contiguous, and Ghana's area total is
  dominated by this one feature. 52 footprints exceed 1,000 ha; excluding the
  largest, the total is 691,117 ha.
- **"Detected" is not "mining."** These footprints are the ground scar an optical
  sensor sees. Quarries, cleared farmland and abandoned workings look similar from
  orbit, and a footprint carries no date of activity.
- **Two West Africa files exist.** This analysis uses
  `WestAfrica_EI_2026-06-24-dissolved.geojson`. An earlier
  `WestAfrica_EI_2026-06-23-dissolved.geojson` sits in `results/results/` with
  9,642 features; only 4,961 geometries are identical between the two.
- Area names in the boundaries file are **double-encoded UTF-8**
  (`Bétaré-Oya` is stored as `BÃ©tarÃ©-Oya`). `analyse.py` repairs them on load;
  anything else reading that file will need the same fix.

## Protected areas

`protected_areas.py` reuses the clipping method above against a WDPA extract and
writes `detections_by_protected_area.csv` plus `protected_areas_summary.json`,
answering: how many protected areas carry detected mining, which carry the most
(by count, by hectares, and by share of their own area), and what fraction of all
detected mining sits inside protection.

Four filtering decisions follow UNEP-WCMC's own coverage guidance, and each is
logged when it fires, because each changes the answer:

| Excluded | Why |
|---|---|
| `STATUS = 'Proposed'` | not protected yet |
| `MARINE = 2` | purely marine, no land to mine |
| `DESIG_ENG = 'UNESCO-MAB Biosphere Reserve'` | includes transition zones that are not protected |
| point geometries | protected areas with no mapped boundary cannot be overlaid |

The point exclusion is a real coverage gap, not a rounding error — the script
reports the count so it can be stated. Overlapping protected areas are kept
separate for the per-area ranking but dissolved into a union for the single
"total mined area inside protection" figure, so a Ramsar site sitting inside a
national park is not counted twice.

Once it has run, the map gains a **Show protected areas** toggle drawing the
outlines over the choropleth, and the page's "Take the data" section gains the
per-protected-area table as a download.

**On redistribution.** The WDPA licence forbids passing the database on without
written permission from UNEP-WCMC, so the page never offers the boundaries for
download — only our own derived statistics, with a link out to Protected Planet
for the source. `protected_areas.py` follows the same line when it writes
`protected_areas_map.json`: it exports geometry and a name for drawing, and no
part of the WDPA attribute table.

Two caveats specific to this question. **Forest reserves are unevenly covered** by
the WDPA — for Ghana in particular, the Forestry Commission's own reserve
boundaries are more complete, and galamsey reporting usually needs them. And the
WDPA is **revised monthly**, so record the release you used; figures are not
comparable across releases.
